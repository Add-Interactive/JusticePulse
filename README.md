## 🛠️ Comprehensive Feature Breakdown

### 1. 🛑 Dedicated ICE & Tactical Police Squad Encounter Shield
* **Digital Red Cards (Tarjetas Rojas)**: High-contrast, full-screen display engineered to press against closed windows or glass doors with 1-click printable wallet PDFs.
* **10-Language Neural Speech Synthesizer**: Broadcasts 5th Amendment silence and 4th Amendment search refusal statements aloud over device speakers in **English, Spanish, Haitian Creole, Mandarin Chinese, Arabic, Vietnamese, Portuguese, French, Tagalog, and Korean**.
* **Optical Warrant Camera & OCR Scanner**: Real-time camera simulator with visual bounding boxes detecting DHS Form I-200 / Form I-205 administrative flags vs. valid Judicial Search Warrants signed by Court Judges.
* **Youth & Juvenile Interrogation Defense**: Enforces *J.D.B. v. North Carolina* (564 U.S. 261) and *In re Gault* (387 U.S. 1) protections against coercive School Resource Officer (SRO) questioning, smartphone searches (*Riley v. California*), and illegal field photography (*Terry v. Ohio*).
* **50-State Sanctuary & Detainer Limits Matrix**: State-by-state statutory index comparing TRUST Act sanctuary states against high-risk 287(g) cooperation mandates.
* **Family Caregiver Affidavit Generator**: Interactive legal wizard executing emergency child custody designation and financial power of attorney with 100% local device sanctuary privacy.
* **Encounter Defense Training Simulator**: Interactive scenario training module awarding certified Level 1 Constitutional Defender badges.

### 2. 🚨 In-HUD SOS Emergency Encounter System
* **Encounter Mode Switcher**: Select between **ICE Stops, Juvenile & Tactical Squads, Front Door Encounters, Traffic Checkpoints, or General Police Stops**.
* **In-HUD Emergency Toolkit**: Launch Red Cards, voice broadcasts, warrant verifiers, or emergency guardian alerts directly from the live recording canvas.
* **Off-Device Encrypted Streaming**: Real-time cloud video chunking with SHA-256 fingerprinting so evidence is preserved even if the device is seized or destroyed.
* **GPS Telemetry & SMS Dispatch**: Dispatches automated Google Maps coordinate links and legal assertion scripts to 3 emergency contacts and legal hotlines.

### 3. 🔍 FBI-Grade Evidence Command Suite
* **Detective Corkboard (`FBIEvidenceHUD.jsx`)**: Drag-and-drop evidence canvas with interactive polaroid photos, witness cards, and dynamic SVG elastic red yarn connections.
* **Multi-Cam Synchronized Video Studio (`MultiCamStudioView.jsx`)**: 4-angle synchronized playback (Bodycam, Dashcam, Bystander, CCTV) with acoustic decibel waveform analysis.
* **Veritas AI Deposition Room (`DepositionSimulatorView.jsx`)**: Real-time witness impeachment, contradiction alerts, and cross-examination coaching.
* **Cryptographic Evidence Vault (`EvidenceVaultView.jsx`)**: Immutable chain of custody ledgers with SHA-256 checksum certification.
* **Section 1983 Generator (`ComplaintGeneratorView.jsx`)**: Automated federal complaint pleadings for civil rights litigators.

### 4. 💼 Standalone Investor Capital & Production Roadmap Portal
* **Dedicated Full-Screen Command Center**: Live round metrics ticker ($3.5M Seed ask, $18.5M Pre-money valuation, 82% target gross margin, $42.8B TAM).
* **6-Stream Monetization Engine**: B2B LegalTech SaaS, Municipal Oversight APIs, On-Demand Forensic Rule 1006 Packets, Contingency Retainer Marketplace, Expert Witness Escrow, and CLE Certifications.

## 🚀 Quick Start & Installation

### Prerequisites:
- Node.js 18+ and npm installed.

### 1-Click Launch (Windows):
Double-click **[`launch.bat`](file:///C:/Users/bekin/Desktop/Social%20Justice/launch.bat)** on your Desktop!

### Manual Terminal Setup:
```bash
# Clone the repository
git clone https://github.com/Add-Interactive/JusticePulse.git

# Navigate to project directory
cd "Social Justice"

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

Open your browser to: **`http://localhost:3000`**
